Screens

    Labels line up with the keys

    The screen is split into a 2 × 4 grid, 61 px per cell, so each label sits right above its key. The small number tag in each corner matches the key under it.

    Only what changed redraws

    A key press inverts one cell; a layer switch redraws the grid; the header stays put. Every partial redraw leaves a faint ghost of the old image, so the firmware does a full, flashing refresh at boot and every ~50 partial updates to clear it.

    The knob shows steps, not a level

    The popup opens on the right edge, pointing at the knob beside the screen, and the header's KNOB: label sits on that side too. SpaceDeck only sends “volume up” and “volume down”, so the popup counts clicks (+3) instead of guessing the Mac’s volume. It closes 1.5 s after the last click.

    Ambient mode

    After 5 min with no input. The wave is generated on the pad. Making it follow your music would need a small I2S mic or a Mac helper app sending levels over Bluetooth. The first key press only wakes the screen, so it never fires a shortcut by accident.
